# Site autônomos/MEI — MVP gratuito

Site estático com guias práticos e calculadora de preço por hora para autônomos e MEI.

## Como publicar grátis

### Cloudflare Pages (recomendado)
1. Envie esta pasta para um repositório GitHub.
2. Vá em Cloudflare Pages → Conectar ao GitHub.
3. Selecione o repositório.
4. Build settings: nenhuma (site estático). Publicar diretório raiz `/`.
5. Publique. O site fica online em https://seu-repo.pages.dev.

### Netlify
1. Arraste esta pasta para Netlify Drop ou conecte ao GitHub.
2. Publique como site estático.

### Vercel
1. Conecte o repositório GitHub.
2. Configure como site estático (framework: Other).
3. Publique.

## Estrutura
- `index.html` — home
- `calc.html` — calculadora de preço por hora
- `como-cobrar-pix.html` — guia de cobrança PIX
- `preco-hora.html` — guia de precificação
- `sitemap.xml`, `robots.txt` — SEO básico
